# Licence decision · ITC Club Hub
Version 1.0 · 2026-11-10 · Lead: Cheng Varyroitanak 

| Criterion                               | MIT | Apache-2.0 | GPL-3.0 |
|-----------------------------------------|-----|------------|---------|
| Anyone (incl. companies) may reuse      | Yes, with almost no conditions | Yes, with notice and change-marking conditions | Yes, but derivatives must also be GPL |
| Improvements must be shared back        | No | No | Yes (copyleft) |
| Explicit patent grant                   | No | Yes | Yes |
| Compatible with GoogleTest (BSD-3)      | Yes | Yes | Yes (BSD-3 code can be used in GPL-3.0 projects) |
| Simple for future student teams         | Yes: short, easy to read | Medium: longer text, NOTICE rules | Hard: future teams must also use GPL |
| Instructor / institute requirement      | N/A | N/A | N/A |

**Decision:** MIT
**Rationale:** Club Hub is a student project with no patent-sensitive code and no need to force others to share changes. MIT is short, easy for future student teams and clubs to understand, and lets anyone reuse or extend the code. It is compatible with GoogleTest (BSD-3-Clause), which we only use for tests. We checked with the TA and the course has no required licence. Every member agreed to it, since each member owns the copyright of their own contributions.
